# Typer C Program Game

Game tes kecepatan mengetik berbasis C terminal dengan berbagai mode permainan, sistem autentikasi, dan leaderboard.

##  Cara Jalankan Program (Quick Start)

### Opsi A: Mengunduh Executable (.exe)
1. Buka bagian **Releases** di repositori ini.
2. Unduh file `TyperGame.zip` versi terbaru.
3. Ekstrak file ZIP dan jalankan `TyperGame.exe` secara langsung (Khusus Windows).

---

### Opsi B: Compile Manual dari Source Code

#### Persyaratan System:
* Windows OS (menggunakan pustaka `<windows.h>` dan `<conio.h>`)
* C Compiler (GCC / MinGW / Dev-C++ / Code::Blocks)
